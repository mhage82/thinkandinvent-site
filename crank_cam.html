CAM Signal Generation

The CAMshaft signal is configured with a user-defined pattern. The pattern alternates between HIGH and LOW levels for specified angular widths (in degrees).

Example: {15, 15, 75, 15, 75, 75, 15, 75} with a starting level of HIGH would generate: HIGH for 15°, LOW for 15°, HIGH for 75°, LOW for 15°, and so on.

This pattern repeats over the full 720-degree cycle.

CAM Sync Detection

A special 15/15 pulse width is used as a synchronization marker. The system detects a unique CAM pattern by identifying consecutive 15° high and low segments.

This provides a clear sync point within the engine cycle, enabling cylinder identification and phase alignment.

Engine Position Tracking

The crank generator tracks angular position from 0 to 720 degrees and also emits the current tooth index (0–59). These are useful for aligning external systems, simulations, or test benches.

Applications

  • Testing embedded software algorithms without real hardware
  • Prototyping engine ECUs (virtual HIL)
  • Creating synthetic test traces
  • Learning tool for internal combustion engine timing
